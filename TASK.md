# Домашнее задание №2: Kafka и ClickHouse

Данные: https://www.kaggle.com/t/1918f3f6435300327d38d6c596f97394

1. Загрузить CSV в топик Kafka отдельным Python-скриптом.
2. Создать отдельный SQL-скрипт DDL таблиц ClickHouse, получающих данные из Kafka в постоянную таблицу.
3. Подготовить отдельный SQL для категории самой крупной транзакции по каждому штату и результирующий CSV. В исходном условии пункты 2–3 частично повторяются.
4. Оптимизировать хранение и изменить DDL, чтобы ускорить запросы.

Оформить GitHub-репозиторий с README, requirements.txt и docker-compose.yml для сборки образов и запуска контейнеров. Инструкция должна позволять запустить проект и проверить его работоспособность.

Оценка 6–7: пункты 1–3. Оценка 8–10: также пункт 4. Результат сдачи — ссылка на GitHub.

Реализация и проверенные команды описаны в [README.md](README.md). Условие предыдущего задания сохранено в [TASK.hw1.md](TASK.hw1.md).
